# Gully

The theme for the Gully Labs blog (blog.gullylabs.xyz), Ghost 6, in the 2026 Gully Labs brand kit (#06050D / #0B0A16 /
#00D2FF / #248BFF / #7B3BFF / #C02CFF / #A3A8C3, Poppins, "You Think It, We Ship It.").

Built on Ghost's [Source](https://github.com/TryGhost/Source) theme, v1.7.6 (MIT, Copyright (c) 2013-2026
Ghost Foundation). The Ghost card layout grid and card spacing rules come from Source; the templates,
styles and scripts are Gully Labs' own. See `LICENSE`.

Third-party parts:
- Fonts: Poppins 500/600/700 (the brand font) and IBM Plex Mono 400/500 (SIL Open Font License 1.1, via
  @fontsource 5.3.0; licences in `assets/fonts`). Self-hosted, nothing from Google Fonts.
- `assets/brand/`: the 2026 Gully Labs brand kit's own files (logo, wordmark, icon, favicons, app icons, badge, OG
  image, two mascots), byte for byte, shown at their exact ratios. Never re-drawn, re-coloured or cropped.
- Icons: lucide 1.49.0 (ISC), inlined as SVG partials; X, GitHub and Telegram marks from simple-icons (CC0).
- `assets/js/lib/reframe.min.js` (MIT, from Source) for responsive video embeds.

Build, preview, packaging and upload notes: `ghost/README.md` in the website repository.
